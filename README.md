# Студийный микрофон · MicStudio

**[Русский](#русский) · [English](#english)**

> 🌐 **Язык интерфейса: только русский** · **Interface language: Russian only**

Обработка микрофона в реальном времени (студийное звучание) — шумодав, эквалайзер, компрессор и другие эффекты, с выходом в виртуальный кабель для игр/стримов/созвонов.

Real-time microphone processing (studio sound) — noise suppression, EQ, compressor and more, routed to a virtual cable for games/streams/calls.

---

## Русский

### Что это
Приложение берёт звук с микрофона, обрабатывает его в реальном времени и отдаёт в виртуальный аудио-кабель (VB-CABLE), который можно выбрать как «микрофон» в Discord, OBS и т.д.

### Возможности
- 🎙 Real-time обработка (низкая задержка)
- 🔇 Шумоподавление
- 🎚 Эквалайзер, компрессор, эффекты (Pedalboard)
- 🔌 Выход в VB-CABLE
- 📟 Значок в трее

### Требования
- Windows 10/11, Python 3.12
- Аудиоинтерфейс (тест: Scarlett 2i2 + Rode NT1)
- Установленный VB-CABLE

### Запуск
- `Студийный микрофон.bat`

---

## English

### What it is
Takes your mic input, processes it in real time, and outputs to a virtual audio cable (VB-CABLE) you can select as your "microphone" in Discord, OBS, etc.

### Features
- 🎙 Real-time processing (low latency)
- 🔇 Noise suppression
- 🎚 EQ, compressor, effects (Pedalboard)
- 🔌 Output to VB-CABLE
- 📟 Tray icon

### Requirements
- Windows 10/11, Python 3.12
- An audio interface (tested: Scarlett 2i2 + Rode NT1)
- VB-CABLE installed

### Run
- `Студийный микрофон.bat`
